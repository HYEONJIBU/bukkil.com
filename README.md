================================================================
 FinVault 사용 매뉴얼 (사용자가 할 일만 정리)
================================================================

FinVault는 DART에 공시된 기업의 사업보고서·분기보고서를 모아 DB로 만들고,
질문하면 그 DB에서 데이터를 꺼내 분석해 주는 도구입니다.
사용 방법은 두 가지입니다.

  A. Claude(클라우드 세션)에게 말로 시키기  ← 권장
  B. 내 PC에서 명령어로 직접 실행하기


----------------------------------------------------------------
 1. 최초 1회 준비 (공통)
----------------------------------------------------------------

[1-1] DART 인증키 발급
  1) https://opendart.fss.or.kr 접속
  2) 상단 메뉴 [인증키 신청/관리] → [인증키 신청]
  3) 회원가입 후 신청 → 이메일 인증
  4) [오픈API 이용현황]에서 40자리 인증키 확인 후 복사

  ※ 인증키는 채팅창에 붙여넣지 마세요. 아래 설정 화면에만 넣습니다.


----------------------------------------------------------------
 2. [방법 A] Claude에게 시키기
----------------------------------------------------------------

[2-1] 클라우드 환경 설정 (최초 1회)
  1) 세션 화면 상단 제목줄의 클라우드 환경 메뉴 클릭 → [Edit]
  2) 환경 변수(또는 API credentials) 항목에 아래 한 줄 추가
        DART_API_KEY=발급받은인증키
  3) 같은 화면의 [Network access]에서 아래 주소 허용
        opendart.fss.or.kr
  4) 저장
  5) 새 세션 시작 (설정은 새 세션부터 적용됩니다)
     - 저장소는 bukkil.com 선택

[2-2] 데이터 수집 요청
  채팅창에 이렇게 입력하세요.

    "삼성전자 수집해줘"
    "SK하이닉스, 현대차 2018년부터 수집해줘"
    "005930 수집해줘"           (종목코드도 가능)

  - 회사 이름이 여러 개 검색되면 Claude가 후보를 보여줍니다. 골라서 답하세요.
  - 이미 수집한 기간은 다시 받지 않습니다.
    최신 분기를 새로 받고 싶으면 "삼성전자 최신 데이터로 업데이트해줘"라고 하세요.

[2-3] 질문하기
  수집이 끝나면 자유롭게 질문하세요. 예시:

    "삼성전자 최근 8분기 영업이익률 추이는?"
    "삼성전자와 SK하이닉스 연간 매출 비교해줘"
    "현대차 부채비율이 가장 높았던 해는?"
    "삼성전자 최근 5년 배당금 변화 보여줘"
    "삼성전자 연구개발비 분기별로 보여줘"
    "최근 4분기 합산(TTM) 기준 ROE 알려줘"
    "DB에 어떤 회사가 들어 있어?"

  질문할 때 아래를 덧붙이면 원하는 형태로 받을 수 있습니다.
    - 기준: "연결 기준" / "별도 기준"         (기본: 연결)
    - 기간: "연간" / "분기" / "최근 4분기 합" (기본: 질문에 맞게)
    - 단위: "억원 단위로" / "조원 단위로"
    - 형태: "표로" / "차트로"

[2-4] 수집한 데이터 보관 (중요)
  클라우드 세션은 종료되면 안의 파일이 사라집니다.
  수집한 DB를 다음 세션에서도 쓰려면 세션을 끝내기 전에 이렇게 요청하세요.

    "수집한 DB 저장소에 저장(커밋·push)해줘"

  ※ 이 저장소는 공개 사이트라 DB 파일도 공개됩니다.
    (DART 데이터 자체는 공개 정보입니다.)
  저장하지 않았다면 다음 세션에서 다시 "수집해줘"라고 하면 됩니다.


----------------------------------------------------------------
 3. [방법 B] 내 PC에서 직접 실행
----------------------------------------------------------------

[3-1] 설치 (최초 1회)
  1) Python 3.10 이상 설치 (https://www.python.org)
  2) 저장소 내려받기
        git clone https://github.com/HYEONJIBU/bukkil.com.git
        cd bukkil.com/finvault
  3) 프로그램 설치
        pip install -e ".[dev]"
  4) 인증키 파일 만들기
     - finvault 폴더의 ".env.example" 파일을 복사해서 이름을 ".env"로 변경
     - 메모장으로 열어 아래처럼 수정 후 저장
        DART_API_KEY=발급받은인증키

[3-2] 데이터 수집
  python -m finvault search 삼성                  회사 검색
  python -m finvault ingest 삼성전자              수집 (2015년~올해)
  python -m finvault ingest 005930 000660 --from 2018
                                                  여러 회사, 시작연도 지정
  python -m finvault ingest 삼성전자 --refresh    이미 받은 기간도 다시 받기

[3-3] 조회
  python -m finvault status                       DB에 있는 회사·기간
  python -m finvault list-metrics                 조회 가능한 표준 지표 목록
  python -m finvault show 삼성전자 -f A           연간 전체 지표 (억원)
  python -m finvault show 삼성전자 -f Q --last 8  최근 8분기
  python -m finvault show 삼성전자 -f TTM         최근 4분기 합
  python -m finvault show 삼성전자 -f Q -m revenue,operating_income
                                                  원하는 지표만
  python -m finvault ratios 삼성전자 -f Q --last 8
                                                  재무비율 (마진, ROE, 부채비율, 증가율)
  python -m finvault account 삼성전자 연구개발     표준 지표에 없는 계정 검색
  python -m finvault items 삼성전자 alotMatter    배당 정보

  옵션 요약
    -f A / Q / TTM     연간 / 분기 / 최근 4분기 합
    --fs CFS / OFS     연결 / 별도 (기본: 연결, 없으면 별도)
    --unit 원/백만/억/조   금액 단위 (기본: 억)
    --last N           최근 N개 기간만

  items 명령에 쓸 수 있는 항목
    alotMatter 배당           hyslrSttus 최대주주
    empSttus 직원 현황        hmvAuditAllSttus 이사·감사 보수
    indvdlByPay 5억 이상 보수  tesstkAcqsDspsSttus 자기주식
    stockTotqySttus 주식 총수  accnutAdtorNmNdAdtOpinion 감사의견
    exctvSttus 임원 현황       otrCprInvstmntSttus 타법인 출자
    irdsSttus 증자·감자        hyslrChgSttus 최대주주 변동
    mrhlSttus 소액주주         cprndNrdmpBlce 회사채 미상환 잔액

 4. 자주 겪는 문제
----------------------------------------------------------------

  "DART_API_KEY가 설정되지 않았습니다"
    → 클라우드: 1-1, 2-1 설정 후 새 세션을 열었는지 확인
    → 내 PC: finvault/.env 파일 이름과 내용 확인 (.env.example 아님)

  "403" 또는 DART 접속 실패 (클라우드)
    → 2-1의 Network access에 opendart.fss.or.kr 허용 후 새 세션 시작

  "[010] 등록되지 않은 키" / "[011] 사용할 수 없는 키"
    → 인증키를 다시 복사해서 넣기 (앞뒤 공백 주의)

  "[020] 요청 제한 초과"
    → 하루 호출 한도(약 20,000건) 초과. 다음 날 다시 수집
       (회사 1곳 전체 수집 ≈ 300~400건)

  "DB에 'OO' 데이터가 없습니다"
    → 먼저 수집 요청 (방법 A: "OO 수집해줘" / 방법 B: ingest 명령)

  "후보가 여러 개입니다"
    → 정확한 회사명 또는 6자리 종목코드로 다시 요청

  특정 지표(예: 매출액)가 비어 있음
    → 금융업 등은 계정 이름이 달라서 생길 수 있음.
       방법 A: "OO 매출 계정 찾아서 보여줘"
       방법 B: python -m finvault account OO 매출


----------------------------------------------------------------
 5. 참고
----------------------------------------------------------------
  - 재무제표 데이터는 2015년부터 제공됩니다.
  - 분기 손익은 해당 분기 3개월 값입니다. 4분기는 "연간 − 3분기 누적"으로 계산한 값입니다.
  - 사업부문별 매출이나 주석 세부 내역은 아직 수집하지 않습니다.
